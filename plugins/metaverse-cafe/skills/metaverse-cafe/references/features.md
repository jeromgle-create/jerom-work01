# 기능 상세

뷰어(`assets/index.html`) 탭: 캐릭터 · 건물 · 동물 · 전체 배치 · **플레이**. 아래는 모두 플레이 탭 기준이다.

## 조작키

| 키 | 동작 |
|---|---|
| W A S D / 방향키 | 이동(카메라 방향 기준). 걷기 2.2 m/s |
| Shift | 달리기 4.6 m/s (Walk 재생 속도 1.9배) |
| Space | 점프(중력 12 m/s², 초기 속도 4.2 m/s) |
| E | 상황별: 메뉴 닫기 > 일어나기 > 카운터(주문/수령) > 손님에게 말 걸기 > 의자 앉기 > 문 열기·닫기 |
| F | 앉은 자리 음료 마시기·쿠키 먹기 |
| Enter | 대화 입력창으로 이동, Esc로 빠져나옴 |
| 숫자 1–5 | 메뉴가 열렸을 때 주문 |

휴대폰(마우스·키보드 없음)에서는 화면 방향 버튼과 E·F 버튼이 나타난다.

## 건물·실내

- 카페 6 × 5 m, 벽 높이 3.2 m. 문(폭 1.2 m)은 경첩 기준 바깥으로 −1.65 rad 열림.
- 실내에 들어가면 지붕(`userData.roof`)을 숨기고 카메라를 바닥 기준 5.2 m로 올린다.
- 카메라→캐릭터 머리 레이캐스트에 걸린 벽면 그룹은 숨긴다(반투명은 표시 문제가 있어 숨김으로 결정).
- 충돌: `userData.collider` 메시의 AABB + 문 박스 + 바리스타 구역 + 서 있는 NPC(반경 0.25 m). 0.4 m 이하 턱은 올라감(기초부 0.35 m, 계단 0.15 m).

## 주문·마시기

- 메뉴(예시 가격): 아메리카노 4,500 / 카페라떼 5,000 / 바닐라라떼 5,500 / 녹차라떼 5,500 / 초코 쿠키 3,000원. 시작 잔액 20,000원.
- 흐름: 카운터 앞 E → 메뉴 → 준비(1.5~4초, 실제 시간 기준 `performance.now`) → 카운터에 놓임 → E로 받기(오른손) → 의자에 앉으면 테이블 앞쪽(테이블 중심에서 0.3 m)에 내려놓음 → F로 한 모금(2.2초).
- 음료 3모금(수면이 내려감), 쿠키 2입(작아짐). 마시는 중에는 일어나기·이동 불가.
- 컵은 `uprightCup()`으로 팔 각도와 무관하게 똑바로 세우고, 팔꿈치 진행도(`drinkLift`)에 비례해 입 쪽으로 최대 0.9 rad 기울인다.

## 손님 NPC (민지·준호·서연)

- 외형: 민지 긴 머리·마른 체형, 준호 모자·크고 듬직, 서연 똥머리·작은 체형.
- 상태 머신: `away → toDoor → enter → queue → toCounter → ordering → toSeat → sitting ⇄ drinking → toExit → away`
  - 문이 닫혀 있으면 열고 들어옴(열어 둔 채). 카운터 손님 자리 2곳(`NAV.counter`).
  - 빈 의자가 없으면 포장해서 나감. 다 마시면 빈 컵을 들고 나가고 5~11초 뒤 재등장.
  - 플레이어가 앞을 막으면 1초 대기 후 옆으로 0.75 m 비켜 감. 말을 걸면 2.5초 멈춰 플레이어를 봄.
  - 다른 접속자가 NPC 의자에 앉으면 NPC가 양보("아, 자리 비켜 드릴게요.").
- 대사: 상태별 대사와 손님별 대사(`lines`)를 번갈아 말풍선으로 표시. 주문 시 "○○ 하나 주세요!", 바리스타 "○○님, ○○ 나왔습니다!".
- 이름표·말풍선은 HTML 레이어에 3D→화면 투영으로 표시하고, 건물 안·밖이 다른 인물의 것은 숨긴다.

## 캐릭터 꾸미기

- 옷 색 6 × 헤어 6(`short, long, bun, cap, ponytail, buzz`) × 체형 4(보통 1.0/1.0, 키 큼 1.08/1.05, 작음 0.9/0.94, 듬직 1.02/1.25 — 키 배율/폭 배율).
- 앉아 있거나 음료를 든 동안에는 변경 불가. 변경 시 캐릭터를 다시 만들고 presence로 즉시 알림.

## 강아지

- 플레이어를 1.3 m 거리로 따라오고 멀면 달림. 플레이어가 앉으면 의자 옆(좌우 0.5 m 중 막히지 않은 쪽)에 와서 `Sit`. 5초 안에 못 가면 그 자리에 앉음.
- `Walk`: 다리 4개 무릎 굽힘, 머리 끄덕임(걸음당 2회)·좌우 흔들기·머리 안정화(몸 bob의 60% 상쇄), 귀 펄럭임, 꼬리·엉덩이 같은 방향 흔들기.
- `TailWag`: 꼬리 ±0.6 rad, 엉덩이 ±0.14 rad 같은 방향.
- `Sit`(6초 반복): 왼쪽 보기 → 갸웃 → 정면 → 오른쪽 보기, 숨쉬기(1.5초), 귀 쫑긋·털기, 꼬리·엉덩이(±0.05 rad).

## 멀티플레이 (claude.ai Artifact `room` capability)

- `claude.use('room')`, `claude.use('user')`가 `null`이면 혼자 보기로 동작(오류 아님).
- presence(초당 최대 10회, 바뀔 때만):
  ```json
  { "v": 1, "p": [x, y, z], "yaw": 0.0, "m": "Idle|Walk|Sit|Drink", "run": 0,
    "look": { "s": 0, "h": 0, "b": 0 }, "seat": 3, "seatAt": 1764300000000, "cup": 12345 }
  ```
  - 플레이 탭을 떠나면 `{ "p": null }`. 받은 값은 모두 검증 후 사용(좌표 |v|<50, 인덱스 범위, 색 0~0xFFFFFF).
- 대화: 토픽 `chat`, 데이터 `{ "t": "최대 80자" }`. Contributor 이상만 보낼 수 있음(`topics: {chat: "interact"}`). 본인 메시지는 에코로 받아 말풍선 표시.
- 이름: `user.profiles([peer.by])`로 해석, 실패 시 "참가자". 이름 문자열을 presence로 보내지 않는다.
- 의자 점유: presence의 `seat`(의자 번호, 건물 traverse 순서)와 `seatAt`. 같은 의자를 두 명이 잡으면 `seatAt`이 빠른 사람(같으면 peer 문자열 순)이 남고 늦은 사람은 자동으로 일어남.
- 원격 아바타는 위치를 보간(10/s), 2 m 이상 차이 나면 즉시 이동(앉기 순간이동 대응).
